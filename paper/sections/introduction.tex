\section{Introduction}

Robotic grasping from free-form language requires more than naming an object in an image. In clutter, an instruction can refer to a target instance, a spatial relation, and an implicit action order: the robot may need to grasp the target directly, or first remove a visible object that blocks access to it. This makes the first-grasp decision a coupled target-grounding and blocker-reasoning problem rather than a simple open-vocabulary classification task.

FreeGrasp~\cite{freegrasp} formalized this setting by combining Molmo-based marked object candidates with vision-language reasoning and language-conditioned segmentation. Its direct answer interface is attractive because it is simple, but it entangles several failure sources. When the selected object is wrong, the system may have misidentified the target, confused two same-class instances, inferred a false obstruction, or sent an unsuitable phrase to the segmentation backend. These errors are especially costly in medium and hard scenes, where the correct first grasp may be a blocker rather than the requested target.

We address this limitation by replacing the direct answer contract with \emph{Evidence-Gated Hierarchical Consensus Routing} (EGHC). Instead of asking a vision-language model for one object ID, EGHC first constructs an auditable evidence packet from deployment-available signals: Molmo candidate IDs and points, predicted mask and spatial evidence, and route-specific consistency checks. A hierarchical routing stage then selects among direct, target-first, and blocker-first reasoning modes. When evidence is weak or inconsistent, the system requests route-specific planning or adjudication rather than committing to the most visually salient candidate.

This paper repositions our previous annotation-assisted v10/S1 analyses as diagnostic upper bounds, not as the main method. The central result is the frozen no-ground-truth EGHC3\_v3 configuration, evaluated on all 900 FreeGraspData instructions. EGHC3\_v3 achieves 60.89\% RSR and 55.22\% SSR without ground-truth semantic features, ground-truth geometry, or benchmark difficulty labels. Relative to the controlled S0 original-protocol baseline under the same Molmo cache, EGHC3\_v3 improves SSR by 7.67 percentage points. Relative to the original FreeGrasp GPT-4o results reported in Table I of the FreeGrasp paper, it improves by approximately 13.6 percentage points RSR and 17.0 percentage points SSR.

Our contributions are:
\begin{enumerate}
    \item We formulate free-form language-guided grasping as an auditable target/blocker decision problem and introduce EGHC, a routing protocol that separates evidence collection, route selection, first-grasp planning, and mask repair.
    \item We implement a deployable EGHC3\_v3 configuration that uses predicted evidence only, with explicit provenance showing no use of ground-truth features or benchmark difficulty labels during inference.
    \item We provide a 900-sample FreeGraspData evaluation against both the published FreeGrasp baseline and a controlled S0 original-protocol baseline, plus a separated S1 oracle upper bound that quantifies remaining headroom.
    \item We analyze failure modes across easy, medium, and hard strata, showing that easy failures are increasingly dominated by mask and instance ambiguity, whereas hard failures remain dominated by blocker and visibility judgments.
\end{enumerate}
