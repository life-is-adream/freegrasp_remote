\section{Introduction}

Free-form language-guided grasping in clutter requires a robot to make several coupled decisions before any low-level grasp planner can act. The system must resolve which instance the instruction refers to, determine whether that instance is immediately reachable, and decide whether the first grasp should target the requested object or a visible blocker. These decisions are easy to conflate in a direct object-answer interface, especially when language refers to object function, part identity, spatial relations, or an implicit action order.

Recent work has made rapid progress on language-conditioned and task-oriented grasping. GraspMolmo learns open-vocabulary task-oriented grasping from large-scale synthetic data~\cite{graspmolmo}; GraspCoT adds physical-property reasoning for flexible instructions~\cite{graspcot}; RT-Grasp and ThinkGrasp use multimodal reasoning for implicit intentions or strategic obstacle removal~\cite{rtgrasp,thinkgrasp}; and VLA-style systems increasingly combine language, perception, and action in a single policy~\cite{graspvla,dexgraspvla}. These systems show that vision-language reasoning is useful for grasping, but they also make evaluation harder to interpret. A failed trial may reflect target-instance confusion, an incorrect blocker decision, an unsuitable segmentation mask, or a downstream grasping failure. Aggregate success rates alone do not reveal which subdecision failed.

We address this limitation by replacing the direct FreeGrasp answer contract with \emph{Evidence-Gated Hierarchical Consensus Routing} (EGHC). EGHC first constructs an auditable evidence packet from deployment-available signals: Molmo candidate IDs and points, predicted mask and spatial evidence, parser validity flags, and route-specific consistency checks. It then gates direct, target-first, and blocker-first reasoning through a hierarchical consensus procedure. The selected route produces a first-grasp ID, and a point-constrained repair stage improves mask consistency without using ground-truth features or benchmark difficulty labels.

The central result is the frozen no-ground-truth EGHC3\_v3 configuration, evaluated on all 900 FreeGraspData instructions. EGHC3\_v3 achieves 60.89\% RSR and 55.22\% SSR. Relative to a controlled S0 original-protocol baseline under the same Molmo cache, it improves SSR by 7.67 percentage points and yields a smaller +3.00 percentage point RSR delta, whose lower confidence bound reaches 0.00 percentage points. A separated S1 oracle diagnostic reaches 67.44\% RSR and 60.11\% SSR, indicating remaining headroom from better visibility and blocker evidence but not a deployable result.

Our contributions are:
\begin{enumerate}
    \item We formulate free-form language-guided grasping as an auditable target/blocker decision problem and introduce EGHC, a routing contract that separates evidence collection, route selection, first-grasp planning, and mask repair.
    \item We implement a deployable EGHC3\_v3 configuration that uses predicted evidence only, with explicit provenance showing no use of ground-truth features or benchmark difficulty labels during inference.
    \item We provide a 900-sample FreeGraspData evaluation against both the reported FreeGrasp baseline and a controlled S0 original-protocol baseline, plus paired uncertainty estimates and a separated S1 oracle upper bound.
    \item We analyze failure modes across easy, medium, and hard strata, showing that easy failures are mainly instance or mask related, whereas hard failures remain dominated by blocker and visibility judgments.
\end{enumerate}
