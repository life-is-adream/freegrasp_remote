\section{Method}

\subsection{Overview}

FreeGrasp++ extends the original FreeGrasp pipeline with protocol-aware reasoning and robust error handling. Figure~\ref{fig:overview} shows the system architecture. The key insight is that \emph{protocol engineering}—explicitly designing how the VLM should reason and what actions to take under uncertainty—can substantially improve robustness without additional model training.

\subsection{Unified Hard-Safe Protocol}

The original FreeGrasp uses a single reasoning prompt for all scenes. We observe that this leads to systematic failures in hard scenes where the target is heavily occluded. Our \emph{Unified Hard-Safe Protocol} addresses this through a structured JSON output schema:

\begin{verbatim}
{
  "target_object_id": 3,
  "target_status": "visible_but_blocked",
  "first_grasp_object_id": 5,
  "action": "remove_blocker",
  "ranked_first_grasp_candidates": [5, 2, 7],
  "confidence": 0.90,
  "evidence": {
    "blocker_evidence": "object 5 covers target"
  }
}
\end{verbatim}

The protocol enforces three key rules:

\begin{enumerate}
    \item \textbf{Hard-safe fallback}: When \texttt{target\_status} is \texttt{visible\_but\_blocked}, \texttt{mostly\_hidden}, or \texttt{uncertain}, the action is forced to \texttt{remove\_blocker}.
    \item \textbf{Confidence threshold}: When \texttt{confidence} $< 0.70$, the system defaults to \texttt{remove\_blocker}.
    \item \textbf{Ranked candidates}: The protocol outputs ordered candidates, enabling fallback if the primary choice fails.
\end{enumerate}

\subsection{Evidence-Gated Hard-Safe Cascade (EGHC)}

The EGHC architecture separates reasoning into independent stages (Figure~\ref{fig:eghc}):

\textbf{Stage 1: Evidence Collection.} Collect scene evidence from Molmo detections, including visible object IDs, spatial coordinates, and depth information. All evidence is sanitized to exclude ground-truth fields.

\textbf{Stage 2: Deterministic Guard Router.} Apply rule-based routing:
\begin{itemize}
    \item \texttt{direct}: Only when target is \texttt{free\_visible} AND no blocking relations AND no mask conflicts.
    \item \texttt{blocker\_first}: When blocking relations exist.
    \item \texttt{target\_first}: Default fallback.
\end{itemize}

\textbf{Stage 3: Conditional Adjudication.} Trigger Qwen adjudication when:
\begin{itemize}
    \item Selected object ID is not in visible IDs.
    \item Direct route but blocking relations exist.
    \item Confidence $< 0.60$.
\end{itemize}

\subsection{Point-Constrained Mask Repair}

Traditional segmentation uses class-name queries (e.g., ``red cup''), which fail when objects are ambiguous. Our \emph{point-constrained mask repair} prioritizes masks containing the Molmo-detected point:

\begin{equation}
\text{score}(m) = \mathbb{1}[\text{contains\_point}(m)] \cdot 2.0 + \text{SAM\_score}(m) - \text{penalty}(m)
\end{equation}

where $\text{penalty}(m)$ penalizes duplicate or implausibly large masks. If the primary mask fails, we try the next candidate from \texttt{ranked\_first\_grasp\_candidates}.
