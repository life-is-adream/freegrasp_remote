\section{Conclusion}

We presented Evidence-Gated Hierarchical Consensus Routing for free-form language-guided grasping. The method changes the FreeGrasp decision contract from a direct object answer into an auditable target/blocker process with deployment-available evidence, route-specific planning, hierarchical consensus, and point-constrained mask repair.

On 900 FreeGraspData instructions, the frozen EGHC3\_v3 configuration achieved 60.89\% RSR and 55.22\% SSR without ground-truth features or benchmark difficulty labels. It improves the controlled S0 original-protocol baseline by +7.67 pp SSR and yields a smaller +3.00 pp RSR delta, with stronger bootstrap support for the SSR gain. It is also descriptively higher than the reported original FreeGrasp GPT-4o baseline by approximately +13.6 pp RSR and +17.0 pp SSR. The separated S1 oracle result of 67.44\% RSR and 60.11\% SSR shows remaining headroom but is not a deployable method result.

\textbf{Limitations.} EGHC still struggles in hard scenes, where blocker and visibility inference remain unreliable. The method can only route over marked candidates and predicted evidence: if Molmo fails to mark a critical target or blocker, the evidence packet has no object ID for that instance and the router cannot recover it. The single-view setting further limits physical visibility reasoning, so logical routing cannot infer hidden 3D structure or resolve severe occlusion by itself. Easy-scene failures increasingly reflect instance-mask ambiguity, whereas hard-scene failures often occur before segmentation. The scene-clustered paired bootstrap supports the controlled SSR gain over S0, while the smaller RSR gain should be interpreted more cautiously because its lower confidence bound reaches 0.00 percentage points. The present evidence is offline benchmark RSR/SSR and VLM-call counts, not wall-clock closed-loop latency or full real-robot sequence success.

\textbf{Future work.} The next step is to strengthen predicted visibility and blocker evidence, add fallback mechanisms for unmarked candidate regions, improve mask-instance disambiguation, and validate whether RSR/SSR gains translate to multi-step real-robot grasp execution.
