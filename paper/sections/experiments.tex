\section{Experiments}

\subsection{Experimental Setup}

\textbf{Dataset.} We evaluate on FreeGraspData~\cite{freegrasp}. The evaluation set contains three language splits. Each split has six strata: Easy, Medium, and Hard scenes, each with and without ambiguity. We use all 900 instructions.

\textbf{Metrics.} RSR measures whether the selected first-grasp object ID is acceptable under the benchmark grasp-order annotation. SSR measures whether the predicted first-grasp mask reaches IoU $\geq 0.5$ with an acceptable ground-truth mask. We report both metrics because correct reasoning can still fail at segmentation, and an accidental mask overlap should not be treated as a correct target/blocker decision.

\textbf{Baselines.} We compare against the original FreeGrasp GPT-4o results reported by Jiao \emph{et al.}~\cite{freegrasp}. We also include S0, a controlled same-cache baseline that runs the original FreeGrasp protocol with the same MiMo-v2.5 backbone and the same reused Molmo cache as EGHC3\_v3. Finally, S1 is reported only as an oracle upper bound because it uses ground-truth-derived features and benchmark difficulty labels.

\textbf{Implementation.} EGHC3\_v3 uses MiMo-v2.5 as the main VLM, a route guard recorded as \texttt{eghc\_consensus\_v1}, and \texttt{eghc\_mask\_repair\_v1} for segmentation repair. The run uses the preserved Molmo cache recorded in the run manifest (SHA-256 prefix \texttt{705d0883}). The full run manifest records 1889 reasoning calls, 900 router calls, 59 repair calls, and 2.10 calls per sample.

\subsection{Main Results}

Table~\ref{tab:main} shows the headline comparison. EGHC3\_v3 achieves 60.89\% RSR and 55.22\% SSR over 900 instructions. The original FreeGrasp GPT-4o row is a reported prior-paper baseline, so we treat the approximately +13.6 percentage point RSR and +17.0 percentage point SSR differences as descriptive rather than paired. The controlled comparison is S0, which uses the same 900 rows and reused Molmo cache; against S0, EGHC3\_v3 improves RSR by +3.00 percentage points and SSR by +7.67 percentage points.

This mask-level evidence is necessary but not sufficient for robotic execution, where benchmark IoU must still be validated in closed-loop grasp trials.

Table~\ref{tab:oracle} separates the deployable method from the oracle diagnostic result. S1 reaches 67.44\% RSR and 60.11\% SSR, but it uses annotation-derived features and benchmark difficulty labels. The gap between S1 and EGHC3\_v3 is 6.55 percentage points RSR and 4.89 percentage points SSR, suggesting that more accurate predicted visibility and blocker evidence could still improve the deployable pipeline.

\subsection{Failure Analysis}

We further categorize all non-joint-success cases in the 900-sample EGHC3\_v3 run. A sample is counted as joint success only when both the first-grasp ID is acceptable and the mask reaches the IoU threshold. The taxonomy is mutually exclusive. If the ID is correct but the mask fails, we assign either \emph{correct reasoning, failed mask} or \emph{no usable mask}, depending on whether the segmentation backend produced a usable point-consistent mask. For reasoning failures, we use the benchmark first-grasp set to determine whether the target itself was an acceptable direct grasp; this separates wrong target instances, wrong blockers, direct grasps when a blocker was needed, and blocker-first decisions when direct target grasping was possible.

Table~\ref{tab:failure_taxonomy} shows that the remaining errors are not uniform across difficulty levels. In easy scenes, all failures are target-instance or mask related: 36 cases choose the wrong target instance, while 40 cases have a correct or otherwise plausible ID but fail at mask selection or point-consistent segmentation. This matches the high easy-scene RSR in Table~\ref{tab:strata}. In medium and hard scenes, the bottleneck moves earlier in the pipeline. Wrong blocker selection and direct grasping when blocker removal was required account for 115 of 131 medium failures and 201 of 224 hard failures. We observe no blocker-first errors when the benchmark target was directly graspable, which suggests that the conservative gate rarely invents blockers in easy direct cases; the dominant remaining limitation is instead missing or misidentifying true blockers under occlusion.

\subsection{Statistical Verification}

We compute paired, scene-clustered bootstrap confidence intervals over the 900 aligned rows. The paired key includes split, stratum, row index, scene ID, query object ID, and annotation text; bootstrap resampling is clustered by scene ID to account for repeated visual evidence. Table~\ref{tab:bootstrap} reports paired deltas in percentage points. EGHC3\_v3 improves S0 by +3.00 pp RSR with a 95\% CI of [0.00, 5.95] pp and by +7.67 pp SSR with a 95\% CI of [4.19, 11.33] pp. We therefore treat SSR as the stronger controlled empirical gain and report RSR as a positive but more cautious gain. The S1 oracle diagnostic remains above EGHC3\_v3 by +6.56 pp RSR and +4.89 pp SSR, confirming measurable headroom from oracle visibility and routing evidence.
