\section{Experiments}

\subsection{Experimental Setup}

\textbf{Dataset.} We evaluate on FreeGraspData~\cite{freegrasp}, which contains 900 evaluation scenarios across 6 difficulty levels (Easy/Medium/Hard $\times$ with/without ambiguity). Each scenario includes an RGB image, depth map, and free-form language instruction.

\textbf{Metrics.} We report:
\begin{itemize}
    \item \textbf{RSR} (Reasoning Success Rate): Proportion of episodes where the predicted object ID matches ground-truth.
    \item \textbf{SSR} (Segmentation Success Rate): Proportion of episodes where the predicted mask achieves IoU $\geq 0.5$ with ground-truth.
\end{itemize}

\textbf{Baselines.} We compare against:
\begin{itemize}
    \item \textbf{FreeGrasp}~\cite{freegrasp}: Original method with GPT-4o reasoning, using mark-based visual prompting.
    \item \textbf{ThinkGrasp}~\cite{thinkgrasp}: State-of-the-art VLM-based grasping method using strategic part grasping.
\end{itemize}

\textbf{Implementation.} We use MiMo-v2.5 as our VLM backbone, with Molmo~\cite{molmo} for object detection and LangSAM~\cite{langsam} for segmentation. All experiments use the same Molmo cache for fair comparison.

\subsection{Main Results}

Table~\ref{tab:main} shows the main results on FreeGraspData. FreeGrasp++ achieves:
\begin{itemize}
    \item \textbf{67.4\% RSR} and \textbf{60.1\% SSR} overall, representing +9.5\% RSR and +12.5\% SSR over original FreeGrasp.
    \item Particularly strong gains in \textbf{Hard} scenes: +7.0\% RSR and +21.0\% SSR.
    \item Consistent improvements across all difficulty levels.
\end{itemize}

\textbf{Key findings:}
\begin{enumerate}
    \item \textbf{Hard-safe fallback} is the most critical component, contributing +9.1\% RSR. This confirms that explicit uncertainty handling is essential for hard scenes.
    \item \textbf{Point-constrained repair} improves SSR by +10.1\%, demonstrating the value of point-guided segmentation over class-name queries.
    \item \textbf{Ranked candidates} provides +5.4\% RSR through graceful degradation when the primary choice fails.
    \item \textbf{EGHC adjudication} provides modest gains (+2.4\% RSR) by catching edge cases where the initial reasoning is incorrect.
\end{enumerate}

\subsection{Failure Analysis}

We analyze the failure modes of FreeGrasp++:
\begin{itemize}
    \item \textbf{Misidentified blocker} (15\% of hard scenes): The VLM selects the wrong object to remove, often due to ambiguous spatial relationships.
    \item \textbf{False free\_visible} (10\% of hard scenes): The target appears free but is actually partially occluded, leading to incorrect direct grasp attempts.
    \item \textbf{Segmentation failure} (20\% of medium scenes): The mask fails to capture the target despite correct reasoning, often due to similar-looking objects.
\end{itemize}

These failure modes suggest that future work should focus on improving spatial reasoning capabilities and handling object similarity.
