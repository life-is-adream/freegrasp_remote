\section{Experiments}

\subsection{Experimental Setup}

\textbf{Dataset.} We evaluate on FreeGraspData~\cite{freegrasp}. The evaluation set contains three language splits. Each split has six strata: Easy, Medium, and Hard scenes, each with and without ambiguity. We use all 900 instructions.

\textbf{Metrics.} RSR measures whether the selected first-grasp object ID is acceptable under the benchmark grasp-order annotation. SSR measures whether the predicted first-grasp mask reaches IoU $\geq 0.5$ with an acceptable ground-truth mask. We report both metrics because correct reasoning can still fail at segmentation, and an accidental mask overlap should not be treated as a correct target/blocker decision.

\textbf{Baselines.} We compare against the original FreeGrasp GPT-4o results reported by Jiao \emph{et al.}~\cite{freegrasp}. We also include S0, a controlled same-cache baseline that runs the original FreeGrasp protocol with the same MiMo-v2.5 backbone and the same reused Molmo cache as EGHC3\_v3. Finally, S1 is reported only as an oracle upper bound because it uses ground-truth-derived features and benchmark difficulty labels.

\textbf{Implementation.} EGHC3\_v3 uses MiMo-v2.5 as the main VLM, Qwen as the constrained verifier and routing gate, a route guard recorded as \texttt{eghc\_consensus\_v1}, and \texttt{eghc\_mask\_repair\_v1} for segmentation repair. The run uses the preserved Molmo cache recorded in the run manifest (SHA-256 prefix \texttt{705d0883}). The full run manifest records 1889 reasoning calls, 900 router calls, 59 repair calls, and 2.10 reasoning calls per sample.

\subsection{Main Results}

Table~\ref{tab:main} shows the headline comparison. EGHC3\_v3 achieves 60.89\% RSR and 55.22\% SSR over 900 instructions. The original FreeGrasp GPT-4o row is a reported prior-paper baseline, so we treat the approximately +13.6 percentage point RSR and +17.0 percentage point SSR differences as descriptive rather than paired. The controlled comparison is S0, which uses the same 900 rows and reused Molmo cache; against S0, EGHC3\_v3 improves SSR by +7.67 percentage points and yields a smaller +3.00 percentage point RSR delta.

\subsection{Split-0 Ablations and Call Budget}

To test whether the EGHC gain is merely a consequence of additional VLM calls, we ran a split-0 ablation that preserves the original FreeGrasp decision contract but asks MiMo-v2.5 twice with the same prompt, token budget, Molmo cache, routing disabled, and baseline segmentation. The two outputs are resolved by a visibility-validity vote. This \emph{budget-2 vote} ablation doubles the original-protocol reasoning call budget from 1.00 to 2.00 calls per sample, but it reaches only 56.67\% RSR and 46.33\% SSR on split 0, below the single-call S0 split-0 baseline. EGHC3\_v3, by contrast, reaches 61.00\% RSR and 56.00\% SSR on the same split. Thus, the controlled split-0 evidence indicates that EGHC's improvement is not explained by simply sampling the original prompt more often; the benefit comes from the routed decision contract and mask repair.

We further isolate the mask-repair component by keeping the same EGHC routing, consensus guard, model, Molmo cache, and split, but replacing \texttt{eghc\_mask\_repair\_v1} with baseline segmentation. This no-mask-repair ablation reaches 61.67\% RSR but only 50.67\% SSR. Compared with full EGHC3\_v3 on split 0, RSR is essentially unchanged (+0.67 pp), while SSR drops by 5.33 pp. This supports the interpretation that point-constrained mask repair mainly improves segmentation consistency after the first-grasp ID has been selected. Disabling the consensus route guard gives 59.00\% RSR and 56.00\% SSR, suggesting that the guard mainly protects first-grasp ID selection while preserving the mask-level gain. Disabling only the constrained verifier while preserving EGHC routing, consensus guard, and mask repair lowers split-0 performance to 53.33\% RSR and 49.33\% SSR, so the verifier appears to contribute useful first-grasp corrections rather than merely increasing the call budget.

\subsection{Failure Analysis}

We further categorize all non-joint-success cases in the 900-sample EGHC3\_v3 run. A sample is counted as joint success only when both the first-grasp ID is acceptable and the mask reaches the IoU threshold. The taxonomy is mutually exclusive. If the ID is correct but the mask fails, we assign either \emph{correct reasoning, failed mask} or \emph{no usable mask}, depending on whether the segmentation backend produced a usable point-consistent mask. For post hoc failure labeling only, we use the benchmark first-grasp set to determine whether the target itself was an acceptable direct grasp; this separates wrong target instances, wrong blockers, direct grasps when a blocker was needed, and blocker-first decisions when direct target grasping was possible.

This pattern is consistent with recent cluttered-scene and grounding benchmarks that identify segmentation and occlusion reasoning as coupled bottlenecks~\cite{graspclutter6d,realvlgr1}, but EGHC localizes the failure to the first-grasp decision, mask quality, or blocker choice. Table~\ref{tab:failure_taxonomy} shows that the remaining errors are not uniform across difficulty levels. In easy scenes, all failures are target-instance or mask related: 36 cases choose the wrong target instance, while 40 cases have a correct or otherwise plausible ID but fail at mask selection or point-consistent segmentation. This matches the high easy-scene RSR in Table~\ref{tab:strata}. In medium and hard scenes, the bottleneck moves earlier in the pipeline. Wrong blocker selection and direct grasping when blocker removal was required account for 115 of 131 medium failures and 201 of 224 hard failures. We observe no blocker-first errors when the benchmark target was directly graspable, which suggests that the conservative gate rarely invents blockers in easy direct cases; the dominant remaining limitation is instead missing or misidentifying true blockers under occlusion.

\subsection{Statistical Verification}

We compute paired, scene-clustered bootstrap confidence intervals over the 900 aligned rows. The paired key includes split, stratum, row index, scene ID, query object ID, and annotation text; bootstrap resampling is clustered by scene ID to account for repeated visual evidence. Table~\ref{tab:bootstrap} reports paired deltas in percentage points. EGHC3\_v3 has a +3.00 pp RSR delta over S0 with a 95\% CI of [0.00, 5.95] pp and a +7.67 pp SSR delta with a 95\% CI of [4.19, 11.33] pp. We therefore treat SSR as the stronger controlled empirical gain and report RSR as a positive but more cautious gain. The S1 oracle diagnostic remains above EGHC3\_v3 by +6.56 pp RSR and +4.89 pp SSR, confirming measurable headroom from oracle visibility and routing evidence.
