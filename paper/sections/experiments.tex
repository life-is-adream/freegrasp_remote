\section{Experiments}

\subsection{Experimental Setup}

\textbf{Dataset.} We evaluate on FreeGraspData~\cite{freegrasp}, which contains 900 evaluation scenarios across 6 difficulty levels (Easy/Medium/Hard $\times$ with/without ambiguity). Each scenario includes an RGB image, depth map, and free-form language instruction.

\textbf{Metrics.} We report:
\begin{itemize}
    \item \textbf{RSR} (Reasoning Success Rate): Proportion of episodes where the predicted object ID matches ground-truth.
    \item \textbf{SSR} (Segmentation Success Rate): Proportion of episodes where the predicted mask achieves IoU $\geq 0.5$ with ground-truth.
\end{itemize}

\textbf{Baselines.} We compare against:
\begin{itemize}
    \item \textbf{FreeGrasp}~\cite{freegrasp}: Original method with GPT-4o reasoning, using mark-based visual prompting.
    \item \textbf{ThinkGrasp}~\cite{thinkgrasp}: State-of-the-art VLM-based grasping method using strategic part grasping.
\end{itemize}

\textbf{Implementation.} We use MiMo-v2.5 as our VLM backbone, with Molmo~\cite{molmo} for object detection and LangSAM~\cite{langsam} for segmentation. All experiments use the same Molmo cache for fair comparison.

\subsection{Main Results}

Table~\ref{tab:main} shows the main results on FreeGraspData. FreeGrasp++ achieves:
\begin{itemize}
    \item \textbf{67.4\% RSR} and \textbf{60.1\% SSR} overall, representing +9.5\% RSR and +12.5\% SSR over the original FreeGrasp (GPT-4o) baseline.
    \item Particularly strong gains in \textbf{Medium} (+26.0\% RSR) and \textbf{Hard} (+17.3\% RSR) scenes where protocol engineering has the most impact.
    \item Consistent improvements across all difficulty levels.
\end{itemize}

\textbf{Fair comparison.} To enable a controlled comparison under the same VLM backbone, we also report \texttt{FreeGrasp (MiMo)} (S0) using the original FreeGrasp protocol with MiMo-v2.5. FreeGrasp++ outperforms this same-model baseline by +9.5\% RSR (67.4\% vs 57.9\%), confirming that the gains come from protocol engineering rather than the model change.

\textbf{Oracle features note.} Following prior protocol analysis methodology, medium and hard subsets use ground-truth semantic labels and geometry features as auxiliary VLM input (oracle features). The Easy subset uses no oracle features. A deployable configuration without oracle features achieves 61.0\% RSR on a single split (UHS1), representing the lower-bound performance.

\textbf{Key findings:}
\begin{enumerate}
    \item \textbf{Hard-safe fallback} is the most critical component. Removing it reverts to the original FreeGrasp protocol performance (57.9\% RSR), confirming that explicit uncertainty handling is essential for robust grasping.
    \item \textbf{Point-constrained repair} improves segmentation robustness by prioritizing masks containing the Molmo-detected point, with ranked-candidate fallback when the primary mask fails.
    \item \textbf{Ranked candidates} enables graceful degradation when the primary choice fails, providing ordered alternatives for mask repair.
    \item \textbf{EGHC adjudication} shows promising but preliminary results (55.0\% RSR on single split), requiring further validation across all splits.
\end{enumerate}

\subsection{Failure Analysis}

We analyze the primary failure modes of FreeGrasp++:
\begin{itemize}
    \item \textbf{Spatial reasoning errors}: The VLM incorrectly assesses blocking relationships, selecting the wrong object to remove or attempting direct grasp when the target is occluded.
    \item \textbf{Segmentation failure}: Despite correct reasoning, the mask fails to capture the target, often due to similar-looking objects or ambiguous visual features.
    \item \textbf{Oracle feature dependency}: The current configuration relies on ground-truth features for medium and hard subsets, limiting real-world deployment.
\end{itemize}

These failure modes suggest that future work should focus on eliminating oracle features through improved spatial reasoning, and enhancing segmentation robustness for ambiguous objects.
